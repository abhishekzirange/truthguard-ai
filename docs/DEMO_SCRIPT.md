# TruthGuard AI — 3-Minute Hackathon Demo Script

## Hook (0:00 - 0:30)
"Judges, Large Language Models are amazing at sounding confident, but notoriously terrible at knowing what has changed. When an AI tells an enterprise developer that *'Python 3.11 is the latest stable release'* or quotes an API price from last year, it doesn't say 'I might be wrong'—it hallucinates with 100% confidence.

Welcome to **TruthGuard AI**: *Don't Trust. Verify.* We built an autonomous verification and freshness intelligence platform specifically designed to detect stale and contradicted answers generated by AI applications."

## The Workflow in Action (0:30 - 1:45)
*(Switch to TruthGuard AI Verification Workspace)*

1. **Input:** "Notice our input workspace. Let's paste a classic stale AI answer:
   `Python 3.11 is the latest stable Python release. FastAPI 0.100.0 is the latest version. PostgreSQL supports JSONB.`
   We select the **Software and APIs** domain and click **Verify Answer**."

2. **Pipeline Telemetry:** "Look at the real-time execution pipeline:
   - First, TruthGuard decomposes the paragraph into three atomic claims.
   - It flags Python and FastAPI versions with **HIGH** temporal sensitivity.
   - It queries **Tavily** for live authoritative release notes on python.org and PyPI.
   - It runs deterministic Semantic Versioning engines alongside our **Bifrost AI Gateway** to analyze the evidence."

3. **Results:** *(Results Screen)*
   "Look at the verdict:
   - Claim 1 (*Python 3.11 is latest*): Flagged as **OUTDATED** with an exact freshness score of 52%. TruthGuard automatically identifies that Python 3.12/3.13 are released, cites python.org, and provides the suggested correction.
   - Claim 2 (*FastAPI 0.100.0*): Flagged as **OUTDATED**.
   - Claim 3 (*PostgreSQL supports JSONB*): Marked as **CURRENT** with high evidence quality, because foundational architectural truths remain valid regardless of elapsed time."

## Deep Dive: Evidence & Freshness Intelligence (1:45 - 2:30)
